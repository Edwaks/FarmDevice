# Паспорт продукта

| Поле | Значение |
|------|----------|
| Название | FarmDevice |
| Репозиторий | FarmDevice |
| Категория | контур Android-устройств для задач TaskCapitan |
| Публичный адрес | https://taskcapitan.ru/ |
| Аудитория | операторы мобильных процессов и владельцы повторяемых сценариев |
| Ценность | организует доступность устройств и прохождение заданий с наблюдаемым результатом |
| Основные сущности | устройства, группы, задания, сеансы, состояния, подтверждения и результаты |
| Ключевые роли | Оператор фермы, Постановщик и Контролёр |
| Язык документации | русский |
| Тип описания | публичное пользовательское |

## Ключевые термины

`реестр устройств`, `группировка`, `назначение задания`, `состояние доступности`, `наблюдение сеанса`, `фиксация результата`, `история выполнения`, `Оператор фермы`, `Постановщик`, `Контролёр`
